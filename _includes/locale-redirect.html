{%- comment -%} Auto-route first-time visitors on the English home (/) to their browser locale. Rules, in order: 1. A saved language choice (localStorage, set by lang-switcher.html on a switcher click or on landing on a localized page) always wins and is applied on every visit to "/" — forever, across sessions, new tabs and bookmarks. 2. Browser-language auto-routing (no saved choice) runs at most once per tab session (sessionStorage), including when the decision is "stay on English" — so reloads and in-site navigation never bounce. 3. Never fires on reload or back/forward navigation (Navigation Timing type), so the browser back button is never fought. 4. Unknown locale, blocked storage, or English -> stay. English is the fallback. Matching: full tag first, then base language. Special cases: - pt / pt-PT -> pt-BR - zh / zh-Hans / zh-CN / zh-SG -> zh-CN; zh-Hant / zh-TW / zh-HK -> English (we don't ship Traditional Chinese; guessing simplified at them is worse) SEO note: this only affects humans' browsers. Crawlers get the same en HTML plus the hreflang alternates emitted in the head, which remain the locale signal for search engines. {%- endcomment -%}
